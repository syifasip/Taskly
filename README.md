<h1 align="center"> TASKLY</h1>

<p align="center">
Taskly merupakan aplikasi manajemen tugas berbasis workspace yang dirancang untuk membantu individu maupun tim dalam mengatur pekerjaan sehari-hari secara terstruktur dan kolaboratif. Aplikasi ini dibangun menggunakan PostgreSQL sebagai basis data utama dan Redis sebagai basis data pendukung, dengan implementasi fitur CRUD, autentikasi JWT, serta Role-Based Access Control (RBAC) untuk mengatur hak akses pengguna secara fleksibel dalam setiap workspace.
</p>

<p align="center">
Taskly juga menyediakan URL unik untuk setiap workspace sehingga berbagai tim dapat bekerja secara terisolasi dalam satu platform. Selain itu, Redis digunakan untuk caching sesi JWT dan sistem pengingat deadline otomatis berbasis TTL, sementara kalender terintegrasi menampilkan seluruh deadline tugas secara otomatis.
</p>
